# DoorStep

DoorStep connects customers with certified home service professionals,
letting them browse services and book trusted providers online in minutes.

## What it does

- Lists home service categories and providers (`/services`, `/providers`)
- Lets customers view pricing and book a service (`/pricing`, `/book`)
- Handles booking submissions through a dedicated API route
  (`/api/booking`)
- Company info and contact pages (`/about`, `/contact`)

## Tech stack

- **Next.js** (App Router) + **TypeScript**
- **Tailwind CSS**
- **Framer Motion** for animation

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it locally.

## Accessibility

Built with accessibility best practices in mind, targeting WCAG 2.1 AA.
